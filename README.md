
# Student Performance Analyzer using Python

## 1. Project Description

Student Performance Analyzer is a beginner-friendly
Python application developed to analyze the academic
performance of multiple students.

The application accepts student details and subject
marks, calculates performance automatically, and
generates a student performance report.

## 2. Objectives

- Collect student names and subject marks.
- Calculate total marks.
- Calculate average marks.
- Identify highest and lowest marks.
- Determine Pass or Needs Improvement status.
- Generate performance reports for multiple students.

## 3. Technologies Used

- Programming Language: Python 3
- Code Editor: Visual Studio Code

## 4. Python Concepts Used

- Variables and Data Types
- Lists
- Dictionaries
- Loops
- Functions
- Conditional Statements
- Exception Handling
- Input Validation

## 5. Features

1. Add multiple student records.
2. Enter marks for multiple subjects.
3. Automatically calculate total marks.
4. Calculate average marks.
5. Find highest and lowest marks.
6. Check student performance status.
7. Display individual student reports.
8. Validate user inputs.
9. View all student reports.

## 6. Performance Calculation

- Total Marks: Sum of all subject marks.
- Average Marks: Total marks divided by the
  number of subjects.
- Highest Marks: Maximum subject mark.
- Lowest Marks: Minimum subject mark.
- Pass: Student must score at least 35 marks
  in every subject.
- Needs Improvement: Student scores below
  35 in any subject.

## 8. How to Execute the Project

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python student_analyzer.py

5. Select the required menu option.
6. Enter student details and subject marks.
7. View the automatically generated report.
